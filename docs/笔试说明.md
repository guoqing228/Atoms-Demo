## 一、一句话说明

用自然语言描述需求，Agent 拆解需求 → 设计界面 → 逐文件写出可直接运行的 HTML/CSS/JS，
结果在浏览器沙箱中**立刻可交互**；不满意继续对话，每次迭代自动存档，可回滚、可分享、可导出。

## 二、实现思路与关键取舍

### 1. 生成内核：两条路径，同一套事件协议

生成体验的核心不是"调用模型"，而是"让生成过程可感知、结果可验证"。所以先把协议定下来：

```
prompt ──► /api/generate（NDJSON 流式）
              │  step / log / plan / file / done / error
              ▼
        AgentProvider（AsyncGenerator<AgentEvent>）
              ├── MockProvider：关键词路由到 13 个手写 recipe，或通用 CRUD 合成器
              └── RealProvider：OpenAI 兼容 / Anthropic 流式接口 + 标签协议解析
```

- **UI 只消费事件流**，不关心背后是 Mock 还是真实模型 —— 这决定了后续换模型不需要改前端；
- **Mock 不是"假数据"**：它是确定性生成器（路由 + 调色板引擎 + 设计语言 + 静态自检），
  同一 prompt 永远得到同一结果，可被自动化测试覆盖；这也是没有 API Key 时保证可体验的兜底方案；
- **真实模型接入（BYOK）已实现并验证**：服务端代理流式转发，Key 不进入前端代码。
  两种协议用本地假 SSE 服务做了端到端测试（`scripts/test-real-provider.mjs`）。

### 2. 生成物：3 文件小项目，而不是一段 HTML 字符串

所有 recipe 输出 `index.html + styles.css + app.js`。这样做换来三件事：

- 右侧「代码」tab 有真实的文件树与逐文件体积/行数，接近真实工程体验；
- 每次生成可做逐文件的版本快照与 diff；
- 预览层可以把 3 个文件内联成一个自包含文档（`src/lib/preview.ts`），在沙箱 iframe 里运行，
  同时注入运行时桥：捕获 `console`/未捕获错误、兜底不可用的 `localStorage`。

预览用 `iframe srcdoc` 而不是部署到独立域名，是这个规模下的主动取舍：
换来零后端、秒级预览、离线可用；代价是分享链接必须内联全部代码（因此用 lz-string 压缩进 URL hash），
以及同源 iframe 的沙箱强度不如独立域（已在 README「已知限制」中说明，后续会升级为独立 origin）。

### 3. 数据：全部本地，不需要账号

项目 / 会话 / 版本存 IndexedDB（Dexie），设置存 localStorage，分享用 URL 编码，导出为单文件 HTML 或 JSON。
没有登录、没有服务端数据库 —— 这让 Demo 可以部署在任何静态/Serverless 平台，
并且"数据持久化"本身成为产品能力而不是账号能力的附属品。

### 4. 设计：亮色纸感 × 精致产品感

- 工作台：暖纸底 + 墨色文字 + 单点强调色（墨绿），衬线标题、等宽小标签、1px 细线分隔、
  大量留白；刻意避开 AI 产品常见的深色 + 紫蓝渐变 + 玻璃拟态。
- 生成的应用：不是"换颜色的同一套模板"，而是 13 个独立设计的信息架构
  （看板列 / 分栏编辑器 / 圆环计时器 / 热力图 / 答题流程 / 棋盘 / 仪表盘 / 播放器…），
  统一使用「克制的产品感」设计规范（见 `docs/recipe-spec.md`）。
- 生成器里的调色板引擎会按 prompt 关键词选主题（浅色优先），并叠加设计语言（极简 / 纸感 / 精密 / 软糖）。

### 5. 工程质量

- TypeScript 严格模式；`pnpm typecheck` 通过；
- 自动化验收脚本：`scripts/check-recipe.mjs` 对每个 recipe 做「生成 → 静态检查 → 语法检查 → 无头浏览器渲染 → 截图」；
- `scripts/test-real-provider.mjs` 用本地假 SSE 服务验证 OpenAI / Anthropic 两条真实模型链路；
- `scripts/shots.mjs` / `scripts/qa-ui.mjs` 做 UI 截图回归与布局/对比度审计（含 390px 移动端）。

### 未做 / 明确取舍

- **未做账号体系与云端同步**：本地优先是主动选择，不是遗漏；
